## Peer review

1. Open each research site and follow one original source. Check whether the page's summary matches the source.
2. Explain one project or portfolio design choice in your own words. Flag a confusing explanation or untested assumption.
3. Open a GitHub issue with the page, section, what you observed, and what would make it clearer.
4. Record the decision and reason in the issue. For an accepted change, link the commit and the check, then ask the reviewer to retry. Close the issue after the retry verifies the fix. Leave unresolved issues open with a next step.
