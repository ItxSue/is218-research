Current projects

Flash Tap

A reaction practice tool with accounts and a private history of saved attempts. The first slice connects signup, a waiting cue, a measured response, saving the result, and sign-out.

Design decision. Keep the button focused through “Wait…” and “TAP NOW” so the same control works with Space, Enter, or a pointer. The labels communicate the state alongside color.

Feedback and response. A reviewer asked which key to press and how to identify the cue. The research page was revised and the reviewer confirmed the explanation was clearer.

Checks. Server checks cover account access, result ownership, duplicate saves, validation, password hashing, and persistence across a new app instance. Safari verified signup, pointer gameplay, saving, and sign-out. The working interface needs a current human peer session.

Code and setup · Plan feedback and recheck

Bench & Bolt

A fictional repair shop’s coordinator needs one queue for intake. The first slice saves a synthetic inquiry in SQLite and displays the exact fields in the coordinator queue.

Scope decision. Local staff intake uses one operating role. New inquiries are Pending review. Later acceptance and completion are described in the plan.

My work and help. I selected staff intake and used Codex to prepare the plan and implementation. Teammate implementation and cross-review remain to be recorded.

Checks. Intake checks cover invalid fields, escaping, form tokens, and persistence. A reviewer clarified the plan’s transition names and rechecked the revised example.
